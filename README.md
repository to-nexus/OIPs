# ONEchain Improvement Proposals (OIPs)

ONEchain Improvement Proposals describe changes to the ONEchain protocol, shared client interfaces, and development processes.
This repository keeps proposal specifications, technical reasoning, discussion references, and revision history together.

See [OIP-1: OIP Purpose and Guidelines](OIPs/oip-1.md) for proposal registration, review, and maintenance.
Application-level standards are maintained separately in [ORCs](ORCs/README.md).
Publishing an OIP does not approve its technical design or activate a change on ONEchain.
