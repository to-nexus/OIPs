# ONEchain Requests for Comments (ORCs)

ORCs define application-level standards for ONEchain, including token interfaces, wallet conventions, and contract interoperability.
They are stored as `ORCs/orc-N.md` and share one number sequence with OIPs; a number cannot be assigned to both.

See [OIP-1](../OIPs/oip-1.md) for registration, review, and maintenance, including the [ORC-specific conventions](../OIPs/oip-1.md#application-standards-orcs).
Start a proposal with the [ORC template](../templates/orc-template.md).
